# 第二版：還原產品，而不是重新設計產品

日期：2026-10-15。

## 依據與邊界

依開發者要求，唯讀檢查三套原專案的版面元件、頁面結構與操作邏輯，再在獨立展示專案重製。沒有修改公司專案，沒有移入原專案程式、設定、API、帳號、品牌資產或營運資料。這不是法律意義的隔離式 clean-room 認證。

入口參考 [1wei.dev 的 Projects](https://1wei.dev/)：以實際預覽、簡短用途與直接入口幫助閱讀，不複製其品牌或網站程式。案例內文則區分原工作職責、問題、處理方式、操作上的改善及公開版限制，不捏造量化成果。

## 三套產品的對齊項目

- 商城：桌機 1220px 主體、紅色搜尋／購物介面、分類側欄與子選單、活動輪播、本週新品、水平熱銷區；商品詳情採圖片與資訊雙欄，手機保留分類捷徑與底部導覽。
- 商城後台：深藍 64px 收合側欄／300px 展開側欄、頁首標題、麵包屑、可關閉的多頁籤。聊天以 300px 會話列表、訊息區、會員側欄組成，支援摘要、會員詳情、訂單列表與詳情的面板內返回。
- POS 後台：獨立營運看板語言、淺藍漸層與半透明卡片、12 欄網格與 9 個預設卡片，提供編輯、排序、尺寸調整與依商家儲存。拖曳之外亦支援按鈕排序及鍵盤尺寸控制。

## 有意保留的展示限制

- 只涵蓋代表性頁面，不是完整原站的所有選單、表單與功能。
- 商品、會員、客服、單據及價格均是展示資料；商品情境圖是獨立生成素材，並非原站商品素材。
- 即時服務、登入、付款與收銀未重現。手機商城的聊天入口明確說明目前僅提供管理員工作台展示。
- 手機看板自動重排，尺寸調整只在桌機開放；各商家的排列設定會分別儲存在本機。
- 尚未經開發者逐頁確認像素與完整互動一致；不宣稱像素級還原。
