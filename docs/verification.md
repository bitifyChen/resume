# 第一版驗證紀錄

驗證日期：2026-10-15。環境：Windows、Node.js 22.14、內嵌 Chromium 瀏覽器。本機正式建置由 Vite preview 提供。

## 自動檢查

- ESLint 通過。
- 14 項 Node 測試通過：結帳與庫存、整批失敗不寫入、聊天訊息條件、未讀、角色權限、庫存異動、CSV 及重設資料。
- 56 份檔案的 UTF-8 與程式外部網址檢查通過。
- Vite 正式建置通過。
- 安裝後完整套件檢查及正式相依套件檢查皆無已知漏洞（以當日 registry 回報為準）。

## 瀏覽器實際操作

- 商城：開啟商品詳情、加入購物袋、以預填虛構資料結帳、跳到後台檢視同一筆訂單。
- 商城後台：訂單標記為配送中、客服傳送文字、編輯、收回、傳送固定展示圖片。
- POS：庫存調整後查詢異動紀錄；切換唯讀角色後，編輯、匯出及不允許的導覽消失；權限矩陣可儲存。
- 在約 1440px 桌機確認客服三欄版面；在 390px 手機尺寸確認商城、客服列表與訊息區、權限頁及展示首頁。
- 修正手機的表格及門店選單寬度；已檢查上述手機頁面的 document scrollWidth 不超過 clientWidth。
- 深淺色模式皆已實際檢視。頁內導覽不改動 hash 路由。

## 驗證範圍

CSV 的解析、原子寫入及錯誤條件已由程式測試驗證；尚未以瀏覽器檔案選擇器完成匯入檔案的端對端回歸。尚未執行 Lighthouse、完整無障礙稽核或 Safari／Firefox 真機驗證。

GitHub Pages 工作流程已建立，但本回合沒有建立遠端儲存庫或執行部署。
