# 實作與後續擴充

## 本版決策

一個 Vite 專案搭配三個案例、三個互動入口。選用熟悉的 Vue 及 JavaScript，透過路由延遲載入區隔各個產品區域；圖表獨立載入。表格、訂單詳情及展示工具列共用，複雜聊天拆為頁面、hook、訊息列表、會員側欄。

使用原專案的技術類型及一般資料夾慣例作為參考；畫面、資料模型與互動實作均於新目錄建立。未搬移原公司的功能程式、商業常數、設定、素材或歷史。

本版優先完成三條可展示流程，非完整複製原系統。原本的資產、風控、支付、商業計算及內部接口不在實作範圍。

## 資料與狀態

- `mock/seed.js`：由商品模板建立完全虛構的資料。倒數及資料時間以首次建立時為基準。
- `mock/operations.js`：純函式。所有修改先複製及驗證，成功後才回傳新資料；結帳及批次匯入具整批成功／失敗語意。
- `mock/repository.js`：版本化的單一 localStorage key，保留記憶體退路。
- `api/demo.js`：模擬 180ms 延遲；未建立 HTTP client。
- `hook/useDemoData.js`：集中成功／失敗提示與快取更新。
- `store/useSessionStore.js`：門店、角色、主題及導覽。

主題採 CSS 變數，預設跟隨初次系統偏好，保留手動選擇。主題只保存自己的 key。設定的介面層級與圓角規則位於共用樣式開頭。

## 可再擴充的方向

1. 商城：註冊與驗證的純展示流程、獨立活動詳情、付款與 QR 畫面模擬。
2. 商城後台：會員列表、雙因素驗證設定示範、更多客服篩選與快捷回覆。
3. POS：商品規格、門店及付款設定、銷售單詳情與商品匯出格式。
4. 品質：保留獨立展示程式，加入跨頁端對端回歸；依正式公開範圍補足瀏覽器及無障礙驗證。

新增功能應先界定要證明的能力，再選取代表流程；不要為了增加頁數納入無法說明的敏感商業規則。
